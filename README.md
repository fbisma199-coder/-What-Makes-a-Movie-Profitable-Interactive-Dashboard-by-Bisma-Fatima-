## 🎬 What Makes a Movie Profitable?
### A Streaming Content Analysis

An exploratory data analysis project investigating the factors associated with movie profitability using Microsoft Excel and Tableau.

### 📊 Interactive Tableau Dashboard
[**Explore the Interactive Dashboard →**](https://public.tableau.com/views/MovieProfitDashboard/MovieProfitDashboard?:language=en-US&publish=yes)

### 📄 Case Study
[**Read the Full Case Study **] https://docs.google.com/document/d/1AZr6YO3vQweqZP06InPsPxPkfvJDEJ3cX1BkDx0eWTg/edit?usp=sharing

### 🛠️ Tools Used
- Microsoft Excel — data cleaning and Pivot Tables
- Tableau Public — interactive data visualization

### 🔍 Key Areas of Analysis
- Movie profitability by genre
- Runtime vs. average profit and ratings
- Release month and profitability patterns

### 📌 Key Takeaway
Family, Animation, and Adventure showed the highest average profit in this analysis. Movies over 120 minutes also showed higher average profit and ratings, although these associations do not establish causation.
