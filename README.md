# -What-Makes-a-Movie-Profitable-Interactive-Dashboard-by-Bisma-Fatima-
Analyzed movie profitability using Excel Pivot Tables and Tableau. Explored genre, runtime, ratings, and release month to identify patterns and support data-driven content decisions. Includes data cleaning, exploratory analysis, an interactive dashboard, key findings, and recommendations. Dataset: Rounak Banik (Kaggle, CC0).
